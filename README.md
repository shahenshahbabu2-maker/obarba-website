# OBARBA — GitHub Pages Website

## Upload to GitHub
1. Create/open your GitHub repository.
2. Upload `index.html` and the entire `images` folder.
3. Make sure `index.html` is in the repository root.
4. Go to **Settings → Pages**.
5. Select **Deploy from a branch**.
6. Select **main** and **/(root)**, then Save.

## Custom domain
After the GitHub Pages site is working:
**Settings → Pages → Custom domain → obarba.com → Save**

Then configure the domain DNS records as described by GitHub.

## Important
Keep the `images` folder in the same repository location as `index.html`; the HTML references images using relative paths.
